ABSTRACT

The Smart Port & Airport Baggage Tracking System is a mission-critical web application developed to monitor, trace, and audit the movement of passenger luggage and container cargo across maritime port berths and international airport terminals. The system handles baggage check-in, tracking across multiple checkpoints, automated misplaced luggage detection, and handling fee invoices.

Developed using Java Spring Boot, the system manages baggage records, airline profiles, checkpoint scans, and dynamic fee calculations. Ground operators can register baggage at entry, generate a unique barcode tag, and complete scans at various transit points. The system also supports automated background checks for misplaced luggage using scheduled SQL operations.

In addition to operations, the system incorporates basic invoicing and carrier management functionalities. It maintains handling fee invoices, tracks payments, and generates operational reports. Facility administrators can monitor baggage status distributions and track outstanding invoice balances, providing a consolidated view of the terminal's operational and financial performance.

INTRODUCTION

1.1 PROJECT OVERVIEW AND OBJECTIVES

The Smart Port & Airport Baggage Tracking System is a web-based management system designed to efficiently manage automated baggage tracking in port terminals. The system handles baggage tags, vehicle/flight entry and exit, transit duration, handling fee calculation, airline management, invoices, and terminal operations.

The application is developed using Spring Boot, MySQL, and Thymeleaf. It also integrates scheduled automation to manage misplaced baggage detection, carrier transactions, and operational metrics. The system provides operational reports to help administrators monitor the overall performance of the terminal handling facility.


Objectives

  • To automate the management of baggage tracking and lifecycle sessions.
  • To record checkpoint scans and automatically flag misplaced luggage.
  • To manage airlines, carriers, tracking services, and related transactions.
  • To automate invoicing and fee tracking operations.
  • To track handling revenue, airline invoices, and terminal operations.
  • To generate comprehensive operational reports for effective facility management.
4

1.2 PROBLEM STATEMENT AND MOTIVATION

Airports and seaports face a growing challenge of misplaced luggage, leading to inefficient manual searches, delayed transfers, and difficulties in managing handling operations. Traditional tracking systems often lack centralized tracking of transit duration, billing, carrier records, and automatic anomaly detection. This creates challenges in maintaining accurate records and monitoring the operational performance of a terminal facility. Manual processes can also result in billing errors, misplaced records, and delays in tracking. The lack of real-time information makes it difficult to identify delayed baggage and manage facility operations efficiently. A unified system is therefore required to connect tracking operations with automated alerts and reporting.

The project is motivated by the need for a centralized and automated tracking management solution that can simplify day-to-day operations. By combining baggage management with automated SQL checks and billing tracking, the system aims to reduce manual effort, improve record accuracy, and provide administrators with a clear view of both tracking operations and invoice performance. The system also provides a structured way to manage airlines, invoices, payments, and tracking activities. This integration can help terminal facilities operate more efficiently while supporting better planning and decision-making. The project also provides an opportunity to apply web technologies to a practical real-world management problem.

SYSTEM REQUIREMENTS & SPECIFICATION

2.1 FUNCTIONAL REQUIREMENTS

The system shall provide the following functional requirements:


Operator & Role Management
  • Manage Terminal Operators and Administrative accounts.
  • Provide restricted access to sensitive financial information.
  • Maintain user information and activity logs implicitly.
Baggage Tracking Management
  • Add, update, and manage unique baggage tags.
  • Track status changes (CHECKED_IN, IN_TRANSIT, MISPLACED).
  • Log physical checkpoint scan locations and times.
Automated Processing
  • Run background tasks to detect overdue transit times.
  • Flag baggage without scans for over 4 hours as MISPLACED.
  • Calculate aggregated handling totals automatically.
Invoice & Airline Management
  • Register and maintain carrier and airline profiles.
  • Generate invoices for handling and terminal fees.
  • Record invoice payments and track due dates.
  • Compare paid amounts against pending balances.
6

2.2 NON-FUNCTIONAL REQUIREMENTS

The system shall provide the following non-functional requirements:


Performance
  • The system should provide quick responses for common operations using JDBC.
  • Baggage registration and search operations should be processed efficiently.
  • Reports should be generated within a reasonable time using SQL aggregations.
Security
  • SQL queries must use parameterized statements to prevent injection.
  • Sensitive passenger data and financial information should be protected.
  • Application configuration should securely store database credentials.
Reliability
  • The system should maintain accurate tracking and financial records.
  • Transactions should be stored consistently in the MySQL database.
  • The system should handle invalid inputs gracefully with Jakarta Validation.
Usability
  • The web interface should be simple and easy to navigate with Bootstrap/CSS.
  • Forms should provide clear instructions and error messages.
  • Operators should be able to access tracking history easily.
Maintainability
  • The application should follow a modular Spring MVC architecture.
  • Code should be organized across Controller, Service, and Repository layers.
  • The MySQL database should maintain structured normalized schema.

CONCLUSION AND FUTURE SCOPE

7.1 PROJECT SUMMARY AND ACHIEVEMENTS

The Smart Port & Airport Baggage Tracking System is a web-based application developed to provide an organized and efficient solution for managing baggage in transport terminals. Built using Spring Boot, MySQL, and Thymeleaf, the system centralizes tracking operations including scan events, transit duration, automated anomaly detection, invoice calculation, and airline management.

ACHIEVEMENTS
  • Developed a centralized system for automated terminal tracking.
  • Implemented baggage lifecycle management with pure JDBC template SQL.
  • Integrated automated background tasks to flag misplaced luggage.
  • Designed a structured MySQL database with appropriate entities.
